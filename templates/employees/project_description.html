Система управления сотрудниками

Этот проект разработан для управления информацией о сотрудниках и рабочих местах.

Функциональность:

  • Управление сотрудниками и их навыками

  • Система уровней владения навыками

Технологии:

  • Django Framework
  • SQLite база данных
  • HTML/CSS шаблоны
  • Система аутентификации Django
